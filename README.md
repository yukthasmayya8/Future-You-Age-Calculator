Future You Age Calculator

Future You Age Calculator is a web application that calculates a user's current age based on their date of birth and predicts their age for a selected future month and year. It also displays the total number of months, weeks, and days lived, the approximate time remaining until the selected date, and the corresponding life stage.

Features

- Calculates current age in years, months, and days.
- Displays total age in months, weeks, and days.
- Predicts age for a selected future month and year.
- Calculates the approximate time remaining until the selected date.
- Identifies the life stage based on the predicted age.
- Validates date inputs and handles invalid selections.
- Provides an interactive interface with gradient styling and animated results.

Tech Stack

- CSS3
- JavaScript

How to Run

1. Clone the repository:
   
   git clone https://github.com/yukthasmayya8/future-you-age-calculator.git

2. Navigate to the project directory:
   
   cd future-you-age-calculator

3. Open "index.html" in any modern web browser.

How It Works

1. Enter your date of birth and click Calculate Age.
2. View your current age and total months, weeks, and days lived.
3. Select a future month and year.
4. Click Predict Future Age to view the predicted age, approximate time remaining, and life stage.

Notes

- The application runs entirely in the browser and does not require a backend or external libraries.
- Future age predictions are calculated for the first day of the selected month.
- The time remaining is displayed as an approximation.
