# Future You Age Calculator

A lightweight, browser-based web application that calculates a user's current age and predicts their age for a selected future month and year.

The application also displays total age in months, weeks, and days, estimates the time remaining until the selected date, and identifies the corresponding life stage.

## Features

- Calculates current age in years, months, and days.
- Displays total age in months, weeks, and days.
- Predicts age for a selected future month and year.
- Estimates the time remaining until the selected date.
- Identifies the life stage associated with the predicted age.
- Validates date inputs and handles invalid selections.
- Provides an interactive interface with gradient styling and animated results.

## Getting Started

### Prerequisites

No additional software, dependencies, or backend services are required. A modern web browser is sufficient.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yukthasmayya8/future-you-age-calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd future-you-age-calculator
   ```

3. Open `index.html` in your preferred web browser.

## How It Works

1. Enter your date of birth and select **Calculate Age**.
2. View your current age in years, months, and days, along with your total age in months, weeks, and days.
3. Select a future month and year.
4. Select **Predict Future Age** to view the predicted age, estimated time remaining, and life stage.

## Notes

- The application runs entirely in the browser.
- No backend or external libraries are required.
- Future age predictions are calculated for the first day of the selected month.
- The displayed time remaining is an approximation.
